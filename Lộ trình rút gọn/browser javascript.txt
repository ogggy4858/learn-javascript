1. Browser environment — window, document, DOM là gì
    - Khi JS chạy trong browser, browser cung cấp cho chúng ta rất nhiều object
    - window đại diện cho browser window/tab hiện tại.
    - Hình dung các object như bên dưới
    window
    ├── document        → trang HTML / DOM
    ├── location        → URL hiện tại
    ├── history         → lịch sử browser
    ├── localStorage
    ├── sessionStorage
    ├── navigator
    ├── console
    │
    ├── setTimeout()
    ├── setInterval()
    ├── fetch()
    └── ...

    - document, DOM, DOM tree, element, node
        + Browser đọc HTML và tạo ra DOM tree, 
            chúng ta sẽ dùng document để truy cập DOM tree này.
            Truy cập, chỉnh sửa thuộc tính của một node trong DOM tree chính là đang chỉnh sửa phần tử HTML
        + Nói cách khác, DOM chính là giao diện (interface) để JavaScript sử dụng để thao tác với HTML
        VD: 
            document.title = '(5) Facebook'; // chỉnh sửa Text của thẻ title
            document.body

        + Sau khi browser parse HTML, nó không còn đơn thuần là một chuỗi text nữa, browser tạo ra một object đại diện cho <h1>.
        + JS có thể lấy object đó
        VD:
            const title = document.querySelector("#title");

        + DOM gồm các thành phần:
            Element
                VD: object tương ứng của thẻ <p> mà trình duyệt parse từ HTML, ...
            Attribute
                VD: href của thẻ a, class của thẻ div, ...
            Text
                VD: Text của thẻ <span>

        + Thông thường sử dụng js để thao tác với HTML như bên dưới
            HTML
             ↓
            Browser parse
             ↓
            DOM
             ↓
            JavaScript lấy DOM object
             ↓
            đọc / sửa / thêm / xóa

1. Một số kiểu dữ liệu / interface cơ bản
    Node
    Element
    HTMLElement
    HTMLDivElement
    HTMLInputElement
    HTMLButtonElement
    HTMLCollection
    NodeList

    - Element kế thừa từ Node, HTMLElement lại kế thừa từ Element, HTMLDivElement & HTMLInputElement & HTMLButtonElement kế thừa từ HTMLElement,
    - Mỗi object DOM đều có thuộc tính chung, đc kế thừa từ HTMLElement, và có những thuộc tính của riêng nó
        VD: có các thuộc tính chung như id, className, ..., các thuộc tính đặc thù như
            input: value, checked, type, placeholder
            button: disabled, type

    - HTMLCollection 
        + Là một mảng chứa các HTMLElement
        + HTMLCollection không phải array, Array.isArray(students); trả về false
        + HTMLCollection có thể loop bằng: for (const element of nodeList) {}
        + Convert về array: const array = Array.from(students); hoặc const array = [...students];
        + HTMLCollection là live, 
            html thay đổi, thì giá trị của biến cũng sẽ thay đổi theo mà không cần gán lại, 
            code dễ gây bug ở chỗ này
        + Các func trả về HTMLCollection:
            • document.getElementsByClassName(className): Lấy tất cả phần tử có class được chỉ định.
            • document.getElementsByTagName(tagName): Lấy tất cả phần tử có tên thẻ được chỉ định (ví dụ: 'div', 'p').
            • document.getElementsByName(name) (Lưu ý đặc biệt): Trên hầu hết các trình duyệt hiện đại, hàm này trả về một NodeList, nhưng trong một số tài liệu cũ hoặc môi trường đặc biệt, nó có thể hoạt động giống HTMLCollection. Nên xem nó là NodeList.
            • element.children: Thuộc tính trả về tất cả các phần tử con chỉ là thẻ HTML của phần tử đó (bỏ qua text và comment).
            • document.forms: Lấy tất cả các thẻ <form> trong trang.
            • document.images: Lấy tất cả các thẻ <img> trong trang.
            • document.links: Lấy tất cả các thẻ <a> và <area> có thuộc tính href.
            • document.scripts: Lấy tất cả các thẻ <script> trong trang.
            • table.rows / row.cells: Các thuộc tính đặc biệt khi thao tác với bảng (<table>), trả về danh sách các hàng hoặc các ô.

    - NodeList là một mảng chứa các Node
        + NodeList không phải array, Array.isArray(students); trả về false
        + NodeList có forEach
        + NodeList có các API iteration quen thuộc như: forEach(), entries(), keys(), values(), for (const element of nodeList) {}
        + Convert về array: const array = Array.from(students); hoặc const array = [...students];
        + Thường là Static (không đổi), trừ trường hợp dùng element.childNodes là live
        + Các func trả về NodeList:
            • document.querySelectorAll(selector)
            • document.getElementsByName(name)

    - Cụm nội dung - content
        + textContent
            Giả sử HTML
                <div id="app">
                    Hello
                    <strong>JavaScript</strong>
                </div>

            Lấy giá trị
                const title = document.querySelector("#title");
                console.log(title.textContent) // Hello JavaScript

            Sửa giá trị
                title.textContent = 'new content';
                -> Sẽ replace hết nội dung bên trong, làm mất thẻ <strong>
                -> <div id="app">new content</div>

        + innerText
            -> Phụ thuộc vào css, nếu css display: none, innerText sẽ không lấy đc giá trị
            -> textContent thì ngược lại, không phụ thuộc vào css, nó lấy trực tiếp Text của object DOM mà không quan tâm đến css
            Giả sử HTML
                <div id="app">
                    Hello
                    <strong style="display: none">JavaScript</strong>
                </div>

                kết quả: Hello

        + innerHTML
            Giả sử html
                <div id="app">
                    <strong>Hello</strong>
                </div>

            Câu lệnh
                app.innerHTML = `
                    <h1>Students</h1>
                    <button>Save</button>
                `;

            Kết quả:
                <div id="app">
                    <h1>Students</h1>
                    <button>Save</button>
                </div>

        + outerHTML
            -> Cũng có thể gán giá trị vào outerHTML nhưng sẽ làm thay đổi chính nó
            Giả sử html
                <div id="app">
                    <strong>Hello</strong>
                </div>

            Câu lệnh
                console.log(app.outerHTML)

            Kết quả
                <div id="app">
                    <strong>Hello</strong>
                </div>

    - Tạo
        + document.createElement(localName[, options]);
            • localName: A string that specifies the type of element to be created (e.g., 'div', 'p', 'button', 'script'). 
                In HTML documents, this argument automatically converts to lowercase.
            • options (Optional): An object containing configuration properties, primarily used for defining custom elements 
                (e.g., { is: "my-custom-button" })
            • trả về HTMLElement

            -> Khi tạo một element không thể app vào 2 nơi cùng lúc
            -> VD:
                const student = document.createElement("div");
                student.classList.add("student");
                student.dataset.id = "100";
                student.textContent = "Nguyễn Văn A";
                document.body.append(student);

        + document.createTextNode(data)
            • data: string
            -> Tạo note kiểu Text

        + document.createDocumentFragment()
            -> tạo ra một đối tượng vùng chứa ảo (chứa các node con) độc lập, không thuộc về cây DOM
            -> Mục đích để tránh trình duyệt phải tính toán lại giao diện và vẽ lại trang (Reflow và Repaint),
                Khi sử dụng createDocumentFragment, các thao tác append chỉ diễn ra trong bộ nhớ, và cần duy nhất 1 lần append vào DOM chính
            -> VD:
                const ul = document.getElementById("myList");

                // 1. Tạo một mảnh tài liệu ảo
                const fragment = document.createDocumentFragment();

                const items = ["Mục 1", "Mục 2", "Mục 3"];

                items.forEach(text => {
                const li = document.createElement("li");
                li.textContent = text;
                
                // 2. Chèn thẻ li vào Fragment (chỉ diễn ra trong bộ nhớ, cực nhanh)
                fragment.appendChild(li);
                });

                // 3. Chèn Fragment vào DOM chính (Chỉ Reflow giao diện 1 lần duy nhất)
                ul.appendChild(fragment);

    - Chèn
        + element.append(...param)
            -> param có thể là object DOM, có thể là string, nếu tham số là string, nó sẽ là Text note
            -> Trả về undefined
            -> Chèn một hoặc các object DOM vào cuối

        + element.appendChild(param)
            -> tương tự append() nhưng appendChild() chỉ nhận 1 tham số
            -> trả về chính tham số đó

        + element.prepend(...param)
            -> Tương tự như append nhưng chèn vào đầu
        
        + targetElement.before(element)
            -> Chèn element lên trước targetElement

        + targetElement.after(element)
            -> Chèn element phía dưới targetElement

        + parent.insertBefore(newNode, referenceNode)
            -> Chèn newNode phía trước referenceNode, cả newNode và referenceNode đều là element child của parent
            -> Nếu không truyền referenceNode, insertBefore sẽ tương tự appendChild

        + targetElement.insertAdjacentElement(position, elementToInsert)
            -> Chèn một phần tử (elementToInsert) DOM vào vị trí position so với targetElement
            -> position có 4 giá trị sau:
                • 'beforebegin': Chèn ngay trước phần tử mục tiêu (làm anh em/sibling).
                • 'afterbegin': Chèn vào bên trong, ngay trước phần tử con đầu tiên của mục tiêu.
                • 'beforeend': Chèn vào bên trong, ngay sau phần tử con cuối cùng của mục tiêu.
                • 'afterend': Chèn ngay sau phần tử mục tiêu (làm anh em/sibling)

        + element.insertAdjacentText(position, text)
            -> Chèn một chuỗi văn bản thuần túy (plain text) vào một vị trí cụ thể so với phần tử hiện tại
            -> position có 4 giá trị sau:
                • 'beforebegin': Chèn ngay trước phần tử mục tiêu (làm anh em/sibling).
                • 'afterbegin': Chèn vào bên trong, ngay trước phần tử con đầu tiên của mục tiêu.
                • 'beforeend': Chèn vào bên trong, ngay sau phần tử con cuối cùng của mục tiêu.
                • 'afterend': Chèn ngay sau phần tử mục tiêu (làm anh em/sibling)

        + element.insertAdjacentHTML(position, text);
            -> Chèn một chuỗi HTML vào một vị trí cụ thể xung quanh phần tử gốc mà không làm hỏng các phần tử hiện có
            -> position có 4 giá trị sau:
                • 'beforebegin': Chèn ngay trước phần tử mục tiêu (làm anh em/sibling).
                • 'afterbegin': Chèn vào bên trong, ngay trước phần tử con đầu tiên của mục tiêu.
                • 'beforeend': Chèn vào bên trong, ngay sau phần tử con cuối cùng của mục tiêu.
                • 'afterend': Chèn ngay sau phần tử mục tiêu (làm anh em/sibling)

    - Xóa
        + element.remove()
